# PPI Planner

Aplicación de escritorio para planificación de tareas con vista Gantt

## Uso

PPI Planner es una aplicación no-comercial para uso interno dentro de la compañia.
Cualquier uso fuera de ese ambito es necesario comunicarlo a los desarrolladores.
